# Astrocytic Metric Control

Synthetic regime analysis for astrocytic metric control of cognitive-state geometry.

This repository contains the code, synthetic data outputs, control analyses, and manuscript-ready analysis figures associated with the manuscript:

**Astrocytic Control of Cognitive-State Geometry: Slow Precision–Phase Coupling in Neural Dynamics**

## Overview

The analysis implements a synthetic neurogeometric model in which astrocytic control variables regulate three operational dimensions of neural-state dynamics:

- **Fisher precision support** — state separability and entropy containment  
- **Hermitian timing support** — phase coherence and loop stability  
- **Finsler transition-cost pressure** — transition burden, fatigue, hysteresis, and recovery  

Five astrocytic control regimes are simulated:

1. Balanced adaptive support  
2. Hypo-support  
3. Over-stabilization  
4. Mistimed support  
5. Reactive noise  

The generated ECoG-like observations are analyzed through state-space, phase-dynamic, transition-boundary, and integrated stability–flexibility metrics.

## Repository contents

```text
├── run_astro_synthetic_v2_final.py
├── run_astro_controls_v2.py
├── requirements.txt
├── manuscript_figures/
├── outputs_v2/
└── outputs_v2_controls/
run_astro_synthetic_v2_final.py generates the primary synthetic regime analysis.
run_astro_controls_v2.py generates the control analyses, including state-label shuffling, phase scrambling, layer ablation, bootstrap estimation, and seed-level robustness.
outputs_v2/ contains primary regime-level outputs and main analysis figures.
outputs_v2_controls/ contains control-analysis outputs.
manuscript_figures/ contains manuscript-ready figure composites.
Installation
pip install -r requirements.txt
Reproducing the analysis

Run the primary synthetic analysis:

python run_astro_synthetic_v2_final.py

Run the control analyses:

python run_astro_controls_v2.py

The scripts regenerate the synthetic outputs, regime-level summaries, control-analysis tables, and analysis figures.

Data status

All datasets in this repository are synthetic and generated by the included scripts. No human, animal, clinical, or personally identifiable data are included.
